# Porthole application

This app is the Mac Catalyst and iPad client for an application's Porthole listener.
It composes `PortholeRemotePresentationModel` with a native Keychain and displays `PortholeRemoteView`.
The host application must explicitly enable remote access and create a pairing invitation.

Build the `Porthole` scheme generated by `./ide --no-open`.
Paste the host's invitation into the pairing field.
Select the enrolled application, then select a current scope.
The capability browser exposes source, context, objects, files, screenshots, logs, persistence, and lifecycle features advertised by the host.
Live changes require approval on the host device.

This target owns application composition only.
Transport and presentation tests live in `PortholeRemoteTests` and `PortholeUITests`.
The Porthole compiler CI job also builds this scheme in Release for arm64 Mac Catalyst.
It uses the pinned Xcode and preserves generation and build logs.
This compile check complements the native host tests. It does not establish iPhone-to-Mac pairing acceptance.

The Acknowledgements tab loads this app's generated attribution report on demand.
It separates shipped libraries from development tools and shows each complete license notice.
Regenerate the report with `./attribution`; `./attribution --check` verifies it against the declared dependency graph.
The app owns its report configuration and resources. CreditKit owns the shared report format.
