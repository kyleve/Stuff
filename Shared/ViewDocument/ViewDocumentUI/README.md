# ViewDocumentUI

See the [ViewDocument guide](../README.md) for composition, validation, and the wire format. This target is declared in the root Package.swift.

Raster images support fit, clipped fill, and tiling. Hosts provide decoded assets; rendering never performs resource loading.
Select `standaloneContentLightDark()` for the fast image gate. `standaloneContentExtended()` retains accessibility captures with the original reference names.
